# Karen Oganesian — Portfolio

Personal portfolio website for Karen Oganesian, a full-stack software engineer.

The site is a dependency-free static GitHub Pages site with English and German
versions:

- https://oganesian.github.io/
- https://oganesian.github.io/de/

## Local preview

Open `index.html` in a browser, or serve this directory with any static web
server.

## Notes

- The site intentionally uses only one local image: `src/img/profilepic.jpg`.
- The previous 2019 portfolio remains preserved in Git under the `legacy-2019`
  tag.
